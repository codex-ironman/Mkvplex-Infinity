## Create the draft release

1. Upload the APK and full source ZIP to a file host that provides direct HTTPS downloads.
2. Open the repository's **Actions** tab.
3. Run **Prepare Mkvplex Infinity APK release** using the direct download URLs for both files.
4. The workflow verifies the SHA-256 checksums and creates draft release `v2.1.5-mkvplex.2`.
5. Review licensing, attribution, corresponding-source completeness, and third-party redistribution rights before publishing.
